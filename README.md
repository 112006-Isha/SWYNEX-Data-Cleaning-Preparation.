# Global Electronics Retailer – Data Analysis

A complete data analysis project based on a global electronics retail dataset. The project includes **data cleaning, preprocessing, exploratory analysis, and visualization** of sales, customers, products, stores, and exchange rates. Using **Excel and Power BI**, the project identifies key sales trends, top-performing products, customer behavior, and business performance to generate meaningful and actionable insights.
